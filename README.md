🧑‍💼 Job Board Interface – Frontend Assignment
A responsive Job Listing application built using React.
This project allows users to browse, search, filter, and sort job postings using static mock data.
The focus of this implementation is clean state management, efficient filtering logic, and responsive UI design.

📌 Features Implemented
✅ Core Features
Display job cards (title, company, location, type)
Filter by location
Filter by job type (Internship / Full-time)
Real-time search by job title
Responsive layout (Mobile-friendly)
⭐ Bonus Features
Alphabetical sorting by title
Highlight searched keyword in job title
🛠 Tech Stack
React (Vite / CRA)
JavaScript (ES6+)
CSS3 / Tailwind CSS
Static JSON mock data

🧠 Implementation Approach
Used React state hooks for managing search and filters.
Applied filtering logic before rendering to ensure efficient UI updates.
Built reusable components for better code organization.
Followed mobile-first responsive layout practices.
📊 Assumptions
Job data is static and stored locally.
Location values are predefined (Remote / On-site).
Dataset is small; pagination not required.
